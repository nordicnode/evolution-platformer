# One Two Hundred — visual direction review

This folder is the **earlier course-kit study**: the screen concepts, the asset
board, the UI kit and the tiling tests from the pass that first replaced the
original outlined art. It is kept for comparison and for the record of the
decision.

It is **not** the source of the shipped atlas. The live art is generated by
`python3 tools/gen_tileset.py` from `tools/art/kit.py`, `kit_cast.py`,
`kit_props.py` and `kit_atlas.py`; the current direction drops the dark object
outline these boards proposed and draws form with value instead. See
`../assets/README.md` for the shipped contract.

## Open the review

Open `index.html` in a browser, or serve the repository with:

```bash
python3 -m http.server 8765
```

Then visit <http://localhost:8765/art-review/>.

## Regenerate the study

The review art is deterministic and generated with Pillow:

```bash
python3 art-review/generate.py
```

That command regenerates *these boards*, not `assets/tileset.png`.

Generated files include:

- `01-title-concept.png` — title/menu direction
- `02-editor-concept.png` — build mode and palette direction
- `03-training-concept.png` — AI training mode
- `04-play-concept.png` — playtest HUD
- `05-replay-concept.png` — replay/ghost presentation
- `06-asset-board.png` — representative pass across terrain, mechanics, characters,
  props, effects, and UI glyphs
- `07-ui-kit.png` — reusable buttons, tabs, cards, badges, and color system
- `08-tiling-test.png` — repeated surface-cell check for grass, sand, brick, wood,
  water, and lava
- `09-complete-atlas.png` — a review candidate in every slot named by the current
  314-sprite live manifest
- `alternate_tileset.png` and `sprites/` — review-only alternate sprite set
- `complete_candidate_tileset.png` and `complete_candidate_tileset.json` — the
  promoted full atlas and its manifest-shaped name list

Regenerate the live atlas with `python3 tools/gen_tileset.py`. The two generators
are separate now: `art-review/generate.py` cannot overwrite the game's art.
